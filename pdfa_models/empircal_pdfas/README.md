# Empirical PDFA Model Artefacts

This directory is reserved for the subspecialty- and severity-specific Probabilistic Deterministic Finite Automata and corresponding alphabet files used in the empirical hybrid simulation experiments.

The final model uses 21 PDFAs, comprising one model for each combination of seven Trauma & Orthopaedics subspecialties and three pathway-complexity cohorts. These artefacts are not currently included in the public repository while the permissions and requirements governing their release are being established.

The absence of the empirical artefacts does not prevent installation, execution of the automated test suite, or use of the demonstration workflow. It does, however, prevent exact reproduction of the empirical hybrid simulation experiments reported in the associated thesis.
