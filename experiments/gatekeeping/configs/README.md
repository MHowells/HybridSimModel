# Gatekeeping Experiments Configurations

This directory contains the configuration files used to run the gatekeeping experiments, which are used to evaluate the outputs of the hybrid model experiments. The common configuration files are located in the `common.py` file, while the specific configurations for each experiment are located in their respective subdirectories.

Some parameters in the `common.py` are currently not reflective of the actual experiment settings. This is while the permissions and requirements governing their release are being established.
